| 项目 | 内容 |
|------|------|
| **测试编号** | TC-001 |
| **测试场景** | 用户以结构化的自然语言描述聚餐场景，包含完整的三要素（金额、参与人、付款人） |

- 自动触发 AA 算账流程（命中"吃饭"+"96"+"多人"）
- 每人应付：96 / 3 = 32.00 元
- 催款消息语气：温和风，包含"麻烦/请/谢谢"
- 账单保存至 records/ 目录

## 测试用例 5：月度汇总查询

| 项目 | 内容 |
|------|------|
| **测试编号** | TC-005 |
| **测试场景** | 用户查询当月聚餐花费总额及欠款情况 |
| **前置条件** | records/ 目录中已有至少 3 笔本月账单记录 |

### 输入

> 帮我汇总一下我这个月聚餐花了多少钱

### AI 执行流程

1. 确定目标月份：当前月份（2026-07）
2. 扫描 records/ 目录下所有 `2026-07-*.md` 文件
3. 解析每份文件提取 total / participants / per_person / payer
4. 计算统计指标
5. 生成汇总报告

### 预期结果

| 指标 | 预期值（基于当时数据） |
|------|----------------------|
| 总次数 | 6 次 |
| 总支出（我垫付） | 816.00 元 |
| 欠款排行榜 | 小明 272 元 / 王强 272 元 |
| 报告格式 | Markdown 表格 + 排行榜 |

### 实际结果

| 项目 | 结果 | 状态 |
|------|------|------|
| 月份识别 | 正确识别"这个月"=当前月 | PASS |
| 文件扫描 | 扫描到全部 6 份记录 | PASS |
| 总次数 | 6 次 | PASS |
| 总支出 | 816.00 元 | PASS |
| 欠款排行 | 小明 272 元, 王强 272 元 | PASS |
| 报告格式 | 表格完整，内容可读 | PASS |
